## 1. Scope

Система призначена для збереження інформації про користувачів, каталог книг із їхніми авторами й категоріями, а також для оформлення замовлень із збереженням точної ціни книг на момент покупки

## 2. Actors

### Humans

1. Guest - гість
   - Переглядати каталог товарів магазину
   - Реєструватися
   - Входити в акаунт
2. Authenticated user - авторизований користувач (розширює гостя)
   - Переглядати каталог товарів магазину
   - Додавати товари до замовлення і змінювати їхню кількість
   - Оформлювати замовлення
   - Ініціювати оплату замовлення
   - Переглядати історію замовлень
3. Admin - адміністратор магазину
   - Входити в акаунт
   - Переглядати каталог товарів магазину
   - Керувати каталогом (книги, автори, категорії)
   - Змінювати статус замовлення
   - Керувати к-стю позицій на складі

### External system

1. Payment service - платіжний сервіс
   - Здійснювати або відхиляти оплату
