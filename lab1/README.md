# Book shop - книжковий магазин

## Domen description

Модель даних для книжкового магазину. Стек - JavaScript/Node. Магазин охоплює художню літературу,
нон-фікш літературу, канцелярію для книг, мерч тощо. З функціоналу: каталог товарів, кошик для замовлень, профілі клієнтів.

## Структура репозиторію

- README.md — опис домену та загальна інформація про проєкт.
- spec.md - текстова специфікація: сутності, атрибути, типи зв'язків та критерії прийняття.
- model.mmd - ER-модель.
- DEFENSE.md - протокол самоперевірки та обгрунтування рішень.
